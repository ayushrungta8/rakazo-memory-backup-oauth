Rakazo Memory Backup

Privacy policy

Updated 30 September 2026.

Rakazo Memory Backup is a self-hosted workflow used only by its owner. It creates backups of the owner's Rakazo memory library, encrypts file contents and names locally with rclone crypt, and stores the encrypted files in the owner's Google Drive.

Google Drive access

Google grants the desktop OAuth client full Drive access so it can use an existing backup folder. The configured workflow uses that access only to create, list, read, and verify backup files in the owner's backup folder. The owner can revoke access in Google Account settings at any time.

Data handling

Backups can contain private conversations, service settings, and credentials. They are encrypted on the owner's server before upload. OAuth tokens and encryption keys are kept in restricted local files controlled by the owner. This workflow does not sell data, use it for advertising, or send it to any third-party service other than Google Drive for storage. This informational site does not collect account data or run analytics.

Retention and deletion

The owner controls the backup folder and decides how long to retain its files. Revoking OAuth access stops future access but does not delete backups already stored in Drive; the owner can delete those files in Drive. The owner can remove local tokens and encryption keys from their computers.
