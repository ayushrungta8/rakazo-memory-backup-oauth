Rakazo Memory Backup

This is a single-user, self-hosted backup workflow for a Rakazo memory library. It encrypts backup files locally, then uploads the encrypted files to the owner's Google Drive. It is not a hosted service or available to other users.

The workflow uses Google Drive access to write and verify files in the owner's backup folder. No backup contents are published on this site.

Read the privacy policy for the exact Drive access and data handling.
